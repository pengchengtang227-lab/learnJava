# 雨宿り · Rainy Corner

一个没有界面元素的日式雨夜便利店微缩三维场景。全部内容搭建在正方形底座内，不含人物。

双击 `index.html` 即可离线打开。也可以在本目录运行 `python -m http.server 4173`，随后访问 http://localhost:4173 。不需要安装 npm 依赖或运行 Java 工程。

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖拽 / 单指拖拽 | 围绕模型旋转 |
| 滚轮 / 双指捏合 | 缩放 |
| 鼠标右键拖拽 / Shift + 拖拽 / 双指移动 | 平移视角 |
| 双击 | 恢复初始视角 |

## 场景内容

- 完整方形底座、L 形街角、停车位、反光斑马线、盲道、排水沟、井盖、小巷。
- 双面透明橱窗、自动门、雨棚、地垫、双面发光招牌、屋顶空调与水管。
- 饮料柜、商品货架、饭团便当区、收银台、咖啡机、关东煮、冰柜、杂志架、宣传海报和后场门。
- 自动贩卖机、自行车、雨伞架、分类回收箱、绿植、公告栏、路灯、电线杆、悬垂电线、路牌、护栏与交通信号灯。
- 持续降雨、屋檐滴水、玻璃水痕、屋顶与路面涟漪、扭曲的实时平面倒影、轻微灯箱闪烁及周期性自动门开合。

使用 Three.js 0.160.1（MIT），库与反射模块均保存在 `vendor`，不使用外部图像、在线字体或 CDN 运行依赖。需支持 WebGL 2 的现代浏览器和硬件加速；桌面浏览体验最佳。商品采用实例化绘制，降雨和涟漪采用批量线段绘制，设备像素比上限为 1.65。
